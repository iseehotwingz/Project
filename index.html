Everything is stored in this browser's local storage. Nothing is uploaded anywhere. Back up regularly.

Import a backup or CSV straight from a web address — easier than downloading a file first, especially on a phone.

CSV format

Import expects a header row. Recognised columns (case-insensitive, extras ignored):

symbol, direction, quantity, entryPrice, exitPrice, entryDate, exitDate, stopPrice, targetPrice, fees, strategy, tags, mistakes, rating, notes, account

Dates accept YYYY-MM-DD or YYYY-MM-DD HH:MM. Direction accepts long/short/buy/sell. Leave exitPrice blank for an open position.
